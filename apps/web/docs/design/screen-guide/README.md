# 반응형 화면 가이드

Paperplane HTML 시안의 데스크톱·태블릿·모바일 화면과 상호작용 상태를 사진으로 정리한 문서입니다.

## 사용방법

저장소 루트에서 미리보기 서버를 실행합니다.

```powershell
node apps/web/preview.mjs
```

`http://localhost:4173/docs/design/screen-guide/index.html`에 접속해 화면별 사진과 설명을 확인합니다.
[HTML 문서](index.html), [화면 데이터](content.json), [오프라인 ZIP](../paperplane-screen-guide.zip)도 제공합니다.
사진은 예시 데이터로 촬영한 시안이며 실제 메일 전달 결과가 아닙니다.
