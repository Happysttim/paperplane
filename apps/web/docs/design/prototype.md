# HTML 디자인 프로토타입

[시안 실행 안내](../../README.md) · [전체 화면 설계](pages.md)

## 확인 방법

저장소 루트에서 `node apps/web/preview.mjs`를 실행한 뒤 `http://127.0.0.1:4173`에 접속합니다. `apps/web/index.html`을 브라우저로 직접 열어도 동작합니다.

상단 **화면 둘러보기**에서 20개 화면으로 이동하고 목록 상태와 다음 요청 실패를 선택할 수 있습니다. 모바일에서는 상단 격자 아이콘을 누릅니다. 새로고침하면 예시 데이터로 돌아옵니다.

## 이번 디자인 보완

| 영역 | 디자인·상호작용 |
| --- | --- |
| 내 이메일 | 데스크톱 행 목록, 모바일 카드, 긴 주소 줄바꿈, 주소 복사와 전달 설정 진입 |
| 전달 조건 | 그룹→항목→검색어 구조, 그룹 간 OR, 각 단계의 AND/OR, 중복 필드는 검색어로 관리 |
| 타입별 입력 | 텍스트 포함/시작/끝, 뉴스레터 선택, 시작·종료 날짜, 첨부파일 이름·확장자 |
| 편집 안전성 | 조건 유형을 되돌리면 기존 값 복원, 미저장 변경 확인, 메일함 인증 후 초안 복귀 |
| 결과 이해 | 입력 즉시 자연어 전달 요약, 샘플 테스트 결과, 값 변경 후 재테스트 안내 |
| 인증 | 비밀번호 표시 전환, 8자·특수문자 체크, 필드 오류, 코드 재요청·시도 제한 예시 |
| 반응형 | 모바일 전체 폭 폼과 하단 저장 버튼, 44px 행동 영역, 태블릿 상단 내비게이션 |

## 검증 범위

- 초기 20개 화면의 390px 모바일 렌더링과 가로 넘침 확인.
- 주소 생성→규칙 저장, 메일함 인증, 목록 오류 복구를 브라우저에서 확인.
- 복수 그룹 저장·재편집, OR 뉴스레터 테스트, 미저장 변경 취소, 인증 후 초안 복원을 확인.
- 문자열 대소문자, 그룹 OR, 날짜 경계, 같은 파일의 첨부 AND, 무효 조건 등 8개 로컬 비교 검증 통과.
- 보완한 주요 폼·목록·소개 화면을 320px, 복합 조건 화면을 768px에서도 확인. 가로 넘침 없음.

## 제품 구현과의 경계

이 결과물은 HTML 디자인 시안입니다. API·OAuth·SMTP 연결, 인증 토큰, 실제 메일, 영구 저장, 운영 페이지네이션은 구현하지 않았습니다. 샘플 날짜는 일자 단위이며 API의 시간대·시각 직렬화는 별도 구현이 필요합니다. 비밀번호·이메일은 실제 값 대신 예시를 사용합니다. 프리미엄은 범위에 포함하지 않습니다.
