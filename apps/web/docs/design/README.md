# UI 디자인

Paperplane의 반응형 화면과 상호작용을 기획한 문서입니다.

## 사용방법

- [화면 설계](pages.md): 페이지별 구성과 이동 흐름
- [상호작용](interactions.md): 입력·오류·로딩·저장 동작
- [HTML 시안 안내](prototype.md): 프로토타입 구성
- [화면 가이드](screen-guide/index.html): 화면 크기별 사진과 설명

HTML 시안을 보려면 저장소 루트에서 실행한 뒤 `http://localhost:4173`에 접속합니다.

```powershell
node apps/web/preview.mjs
```

시안은 예시 데이터를 사용합니다. 실제 React 앱 실행은 [Web 안내](../../README.md)를 참고하세요.
