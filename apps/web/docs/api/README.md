# API 명세

Paperplane API의 요청·응답과 인증 방식을 정리한 JSON 문서입니다.

## 사용방법

[api-reference.json](api-reference.json)을 열고 API의 `path`와 `method`로 항목을 찾습니다.
`request`에서 요청 형식을, `responses`와 `errors`에서 응답을 확인합니다. 공통 구조는 `$defs`에 있습니다.

사용자 정의 JSON 형식이며 OpenAPI 문서는 아닙니다. 실제 서버 실행은 [API 안내](../../../api/README.md)를 참고하세요.
