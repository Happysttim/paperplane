# React 화면 자료

Paperplane React 프론트엔드의 구현 화면을 보관하는 문서 폴더입니다.

## 사용방법

[screenshots](screenshots/)에서 이메일 목록, 로그인, 규칙 편집 화면의 반응형 사진을 확인합니다.
사진은 예시 데이터 기준입니다. 실제 앱은 저장소 루트에서 실행합니다.

```powershell
pnpm dev:web
```

접속 주소는 `http://localhost:5173`입니다. 환경 설정과 검증 명령은 [Web 안내](../../README.md), 요청·응답 형식은 [API 명세](../api/api-reference.json)를 참고하세요.
